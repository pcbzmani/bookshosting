# Ramya S. — Writer Website

A bilingual Tamil/English static writer portfolio with a professional office portrait.

## Folder structure

- `index.html` — main website page
- `assets/css/style.css` — website styling
- `assets/js/main.js` — EN / தமிழ் language switcher
- `assets/images/ramya-office-portrait.png` — optimized website portrait

## Before publishing

1. Replace `YOUR-EMAIL@example.com` with your real email.
2. Replace the placeholder Instagram and LinkedIn links.
3. Add your real book-cover images and article links when ready.
4. Upload the entire `ramya-writer-website` folder to your hosting service.

The language choice is remembered in the visitor's browser using localStorage.
